## Notes
- **Shortest path to APPROVE:** fix C1, preferably C2 too, then run the C3 capture once after the owner logs in. Everything else is follow-up.
- **Report learnings candidate 1** ("a scene field never reached `main`") should not go into the KB as a firmware fact without a minimal repro. Observing a Scene field from `main` through the port is a widely used pattern. HEAD's `main.brs` never called `homeScene.observeField("exitApp", m.port)` at all, so the failing variant was a temporary edit that cannot be inspected now. The dev's own caveat ("may be specific to this channel") is the right framing.
- **Not part of this diff:**
  - `manifest` still has `splash_color=#000000` against the `#0B1222` ground (KB splash-screen-keys-and-pre-decode-colour, summary), and the old icons; both belong to the store-asset follow-up.
  - The legacy grey `Dialog` is not restyled. The plan's Goal lists "the dialog", but no acceptance criterion does, and the report flags it as an `SdDialog` follow-up.
- **The old focus logic is fully gone.** `RowListItemComponent` was replaced as the grid item by `SdTile`, not edited as the plan listed. This is fine, and nothing on the live paths still reads `rowItemFocus`.
- **Unused palette assets ship:** the cyan glows, `sdanavy` grounds, pill radii 3/15/24/29 and `mark_240`. The `sdanavy` set is deliberate (the alternate palette). The rest is dead weight.
