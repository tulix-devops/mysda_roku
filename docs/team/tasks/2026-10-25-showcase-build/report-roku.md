## Summary
The app is now the C · Showcase design (docs/design/showcase.md, boards in docs/design/source/C*.dc.html).
- **Shell.** A new `Sc` shell built like wpa_live_roku's device-proven WpScene: one scene owns the screens, the one Video node, the dialog, sign-in, the clock and a boot watchdog. Requests travel through m.global fields.
- **Screens and navigation.** All eight C screens plus the floating capsule nav.
- **Plumbing kept.** Data, sign-in, the catch-up gate and playback use the existing endpoints, wire formats and registry records, re-implemented as three Tasks that parse off the render thread.
- **Pruned.** The legacy front end is removed on this branch; `main` keeps it. The package went from 3.55 MB to 0.41 MB.

## Decisions
- **Built new rather than restyling legacy.** Showcase is a different information architecture (Home rows, channel pages, series), and the legacy screens are four 840-line clones routed by `navigatedFrom` strings. WpScene's shell is proven on the same device class.
- **Plumbing kept on the wire.** The same URLs, bodies and headers (including both `X-Session-Token` headers check-purchase sent) and the same `AUTH/authData` JSON. A viewer signed in on the old build stays signed in. The `subscribed` flag is still written as 0, as before.
- **Schedules parsed in the Task** and reduced to:
  - today;
  - the 6-day week, one card per title on titled channels;
  - series with ≥ 3 recordings, top 8 × 20 episodes.

  That is about 220 nodes per channel instead of 849 programmes plus a re-serialised 377 KB string on the render thread.
- **Hero "blur".** The grab is decoded at 48x27 and drawn 1920 wide (SceneGraph has no blur), at 55 % under fades.
- **Catch-up gate.**
  - Not signed in → "Log in to watch recordings".
  - Signed in → check-purchase. `yes` plays; `no` offers Account; `unauthorized` clears the session and asks to log in again; `error` offers Try again.
  - A successful sign-in from the gate checks access, then plays the pending item.
- **One focus indicator.**
  - Pills light only while their zone holds focus.
  - A selected chip is white without lift; it lifts only while the chips have focus.
  - Cards lift by the list's own focusPercent, gated on `rowListHasFocus && rowHasFocus` / `gridHasFocus`.
- **Deviations from the boards** (worth an owner look on device):
  1. **Catch-up row titles** combine title and subtitle in one RowList label ("3ABN Homecoming · 57 recordings in the last 21 days"). A RowList label has one font.
  2. **Radio.** The radial glow behind the carousel is not drawn (flat ground). The carousel wraps, so Left never reaches the capsule: Back opens it.
  3. **Live strip.** OK on another channel switches to it. OK on the one playing opens its page. The hint text changes to say which ("OK to watch HopeChannel").
  4. **Russian chip** reads "Russian": Plus Jakarta Sans has no Cyrillic glyphs (checked in the TTF cmap).
  5. **Account.** The wall of grabs uses whatever schedules are loaded; with none loaded it is empty.
  6. **Channel page** title is "Channels / <name>" even when opened from Home.

## Learnings candidates
- **A brighterscript compile on a copy of the repo is a real check for a code-only Roku round.**
  - It catches reserved builtins used as names (`run`, `pos`), calls missing from a component's script scope, and parse errors.
  - An absolute `rootDir` on another drive silently matched 0 files and reported "0 errors"; copy the project under the bsconfig folder.
  - Evidence: 4/4 planted errors caught; 21 real errors fixed this round.
- **Reachability-based pruning beats a literal-filename sweep.**
  - Walk from the scene through XML tags, createChild / CreateObject and itemComponentName.
  - Keep assets by literal path or by path prefix for concatenated names.
  - Evidence: 228 files, 3.55 → 0.41 MB, scope check 51 → clean.
- **A 9-patch pill needs a device-pixel copy for 720p** (applied from the KB): every round shape is generated at r and at floor(2r/3).

**Found on the device and fixed** (commit 0ab8b78):
1. **RowList labels.** The label sits in a band the list reserves above each row's items, about 43 px for a 32-px face. With `rowLabelOffset` y -58, the first label was clipped and the others drew under the cards. Fixed with y 0, and the list's y set to the first label's top.
2. **Card focus.** A 1.0 → 1.07 lift read as no focus. Now the other cards in the focused row step back (94 %, dimmed) and the focused one lifts to 104 % with a shadow.
3. **getdvr.php order.** It came OLDEST first; the context brief said newest first. Today ran backwards. Programmes are now sorted explicitly.
4. **Grab placeholder.** For a programme's first minutes the feed serves one shared grey "play" placeholder at the grab's own URL: identical file, 6542 bytes, same md5 across channels. Grabs are now used only after 10 minutes on air.
5. **Layout.**
   - The Account heading was clipped to one line.
   - The dialog body was clipped: a wrapping Label needs about 40 px per line or it drops lines.
   - The live hint sat under the lifted strip card.
