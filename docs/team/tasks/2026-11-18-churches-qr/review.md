Checklist, all items:
- Hardcoded secrets: none. I grepped the new files for key/token/secret/password/bearer; the only hits are key handling and animation `key=`. The endpoint needs no auth.
- Transport: `https://` only. `ScHttp` sets `common:/certs/ca-bundle.crt` (source/ScNet.brs:25). No custom headers, so redirect header forwarding ([[urltransfer-follows-redirects-and-forwards-custom-headers]]) does not apply.
- Network input parsing: `ParseJson` result is type-checked as an array or `{data:[]}`, non-AA items are skipped, and fields are coerced with `ScStr` (invalid, numbers and bools are handled). Empty state or name is dropped. Values go into Labels as plain text, so no markup is interpreted. Malformed data shows the failure note; it is not silently discarded and overwritten ([[hostile-input-finds-silent-destruction]] does not apply).
- Logging: `ScChurchTask.brs:49` prints the HTTP status and state count only. No PII, no URLs with parameters.
- Dependencies: none added. jsQR is used only by `docs/.../tools/decode-qr.js` from a sibling repo. `tools/deploy.ps1` packages only source/, components/ and images/, so it does not ship.
- WebView, Android manifest, storage: N/A (Roku).
- Injection via dynamic URLs: see S1. No URL is fed to a player.
- Platform claims: no commits, no `Platform-Ready:` trailer, `platforms.yaml` untouched, so N/A.

## Notes
- **Pin drift:** ScChurches.brs and .xml were edited during this review (mtime 00:11:16). From a read of the new file, the edit adds a QR loader (`showLoader`, `qrLoader`, `loaderPulse`), draws a cached code at once instead of after the timer, and moves `qrTimer.control = "stop"` above the empty-link return. None of that is covered here, and line numbers above refer to the pinned file. The new path calls `drawQr` synchronously from `showChurch` on every cached Up/Down, which re-creates up to about 600 Rectangles per key press with no debounce. That adds to C1 and needs a timing check in a re-review.
- BrightScript pitfalls checked in the pinned code: XOR as `(a or b) and not (a and b)` on Integer params is correct; integer `\` is used everywhere a division needs to stay integral; `>>`/`<<` are on Integers; there are no float divisions; and the single-line `if ... then ... else ...` forms are well-formed. The reserved names `run`, `pos`, `step` and `log` are avoided (`rl`, `apos`, `stp`, `lg`). The local `right` in ScQr.brs:135 shadows the `Right()` builtin. It compiles and runs (proven by the device), and `Right()` is not called in that function, so I am not raising it. ScQr.brs is included in the component's script list ([[source-dir-not-in-component-scope]]), and `node tools/check-scope.js` is clean (run on the current tree).
- Panel and QR timer race (pinned): showChurch clears the modules and `m.qrFor` immediately, and onQrTimer re-reads `currentChurch()` when it fires. A code can never be drawn next to another church's name, and a late fire for a church with no link returns early.
